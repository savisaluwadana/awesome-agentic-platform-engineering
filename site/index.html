QUICK ANSWERS

What is agentic platform engineering?

Agentic platform engineering combines AI agent workflows with the tools and controls used to build, deploy, secure, observe, and operate software. It can include agent frameworks, MCP tool servers, Kubernetes platforms, GitOps controllers, telemetry, and policy enforcement. Not every platform tool in this directory is itself an AI agent.

How can an AI agent discover these projects?

Read the structured JSON catalog or Markdown directory, then follow each project’s detail page and official GitHub repository for authoritative information. The sitemap enumerates public project pages for web crawlers.

Who maintains the listings?

Community contributors suggest projects through GitHub pull requests. The public README controls listing names, categories, descriptions, and repository URLs. GitHub stars are external metadata, not votes or endorsements.
